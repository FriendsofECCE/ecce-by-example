GUI steps
1. Builder: build H2CO (e.g. Tools > Add from SMILES... "C=O", or C, O,
   Build > Add Hydrogen), Build > Clean, File > Save.
2. Editor (Calculation Editor), box "ECCE-QM Settings": Theory DFT (DFT
   Functional B3LYP is the default), Quick Basis Menu > 6-31G*,
   Runtype GeoVib; Runtype Details...: tick "Raman activities (about 7 times
   the cost)" (box "Frequencies"; the same dialog has "Localised orbitals
   (bonds and lone pairs, same set for each spin)", ticked by default);
   Close; Save.
   NOTE: the screenshot of Runtype Details was NOT kept: the test hook sets
   the value (the deck has `raman true`, SetupParams UseRaman 1) but does not
   tick the box on screen, so the picture showed it unticked. Retake by hand.
3. Launch... > Launcher: localhost, Processors 2, Launch.
4. Builder > Properties tab > Vibrations > Vibrational Frequencies:
   - tabs Spectrum / Table; an IR | Raman switch at the top right of the
     plot (the panel shows one at a time);
   - click a stick: the box under the plot reads e.g. "Mode 10 . 1851.2 cm-1
     . IR 99.4 km/mol . Raman 2.9 A^4/amu / C=O stretch 67 % H-C-H bend 33 %
     (others < 5 %)" (figure vib-panel-ir);
   - Mode in the viewer: Show, Animation / Vectors, Arrow length, colour,
     Reverse; buttons Open in window..., Composition..., Displace....
5. Open in window...: IR (top) and Raman (bottom) stacked, sticks plus
   broadened envelope (right-hand axes "IR envelope (km/mol per cm-1)",
   "A^4/amu per cm-1"); controls Width 15 cm-1 (the broadening, FWHM),
   Scale factor 1, Sticks, High on left, Range 0 to 3400, Reset zoom;
   Other spectra: Compare... (overlay or mode matching), Difference,
   Experimental..., Remove, Export .csv...; Composition..., Close (figure
   spectrum-window).
6. Geometry Trace: the optimisation (5 steps); y-axis title bug #1041.
