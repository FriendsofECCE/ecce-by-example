ECCE main 23769bf69 (build-cmake of 2026-11-14), 9.5.3-dev. Run 2026-11-14.

How it was done: the tests/launch harness (isolated HOME, local data,
private Xvfb, nice 19), each window driven by its own test hook, nothing
typed: the calculation made with `launchjob create` (project
water-opt-project, calculation water-opt, code ECCE-QM, the rough water
structure); Builder (ECCE_BUILDER_SCRIPT: Build > Clean, File > Save);
Calculation Editor (ECCE_CALCED_SCRIPT: theory, basis, runtype, Theory
Details..., Save); Launcher (ECCE_LAUNCHER_SCRIPT: machine localhost,
processors 2, Launch); Organizer opened on the calculation
(ECCE_ORGANIZER_OPEN); Builder with ECCE_OPEN_PANEL for the results.
Screens captured with `import` on the Xvfb display; black root border
trimmed. Not done through windows: making the project and calculation
(Organizer File > New ... -- help first-calculation steps 1-2) and the
water typed in (the help uses the Structure Library or O + Add Hydrogen).

is ECCE-QM, the example set's ecceqm-water):

   Code row: DFT: QM, G16, ORCA, NWChem ...; Semi-empirical; Periodic.

Things a first-time user may trip over (for the chapter)
- The Runtype menu shows the internal name "GeoVib" (no "Geometry +
  Vibration" label); help xtb.md writes **Geometry + Vibration** as if it
  were the menu text (inconsistent; ecce-qm.md and first-calculation.md say
  GeoVib). Not filed (documentation wording).
- Symmetry: C1 in the editor and the Organizer for water (C2v), with Use
  symmetry ticked, because nobody pressed Find in the Builder's Symmetry
  panel; a reader may wonder. Not a bug.
- Before a basis is chosen the editor shows a red cross and "2 problems that
  will stop this calculation running"; it turns green after the basis and
  Save.
- Changing the runtype prints "WARNING: Changing the runtype overrides all
  runtype detail field changes." in the message area.
- A localhost registered with a queue manager and no queues gives "ERROR: No
  queues are defined for localhost" and a greyed Launch (seen in a first try
  with a test-registered queue machine; a first-start localhost has no
  queue and launches). Worth one sentence only if the chapter covers
  machines.
- Theory Details opens as a separate window over the editor.

Coupling: this is the start of the funnel; Chapter coupling shows a new
calculation in another code from this one's structure (New from This /
workflow New step).
