How ECCE sets this up (checked in the source, scripts/parsers/ai.orca,
src/apps/calced/CalcEd.C, src/dsm/edsiimpl/QstStructures.C,
tests/apps/calced_neb_test.py):
- Transition State: a NEW calculation without a structure; Calculation
  Editor > TS Search ("Structure from other calculations"), pick the
  reactant calculation (its final structure becomes this calculation's),
  run type "Transition State (NEB-TS) + Frequencies", pick the product
  calculation (and optionally a TS guess). Save writes neb_product.xyz
  (renumbered onto the reactant's order) as an input file and the deck gets
  "! ... NEB-TS Freq" with %neb NEB_End_XYZFile "neb_product.xyz",
  Nimages (Runtype Details, default 8), Preopt_Ends only when the end points
  were made at another level. Only calculations of the SAME project are
  offered as reactant/product.
- IRC: run type IRC; Runtype Details: Max Steps per direction (default 20),
  Direction Both/Forward/Backward, Initial Hessian Analytic/Numerical (ORCA
  computes it in the IRC job: %irc InitHess calc_anfreq). Results:
  IRCCOORD/IRCENERGY/IRCGEOM -> Builder panel "IRC Path" (graph or table,
  Export .csv).
