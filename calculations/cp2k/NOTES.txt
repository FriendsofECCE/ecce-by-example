System
------
alpha-quartz, SiO2, P3_121, Levien, Prewitt & Weidner (1980) Am. Mineral. 65,
920: a = 4.9134 A, c = 5.4052 A (00-start-quartz/quartz.cif, the CIF fixture
of the ECCE repository). 9 atoms per cell. The calculations use the 2x2x2
supercell: 72 atoms (Si24 O48), a = b = 9.8268 A, c = 10.8104 A,
gamma = 120 deg, V = 904.1 A^3. Si-O in the start structure 1.604 and 1.614 A
(checked: 96 Si-O bonds below 2 A, four per Si).
Why the supercell: ECCE's CP2K setup has no k-points (Gamma point only; the
missing k-points are listed in issue #412). A 4.9 A cell sampled at Gamma alone
is far too coarse; about 10 A in each direction is the usual minimum for an
insulator with a wide gap such as quartz. This is worth a sentence in the
chapter: with Gamma-only codes the reader makes the cell bigger instead of
adding k-points.

Settings ECCE writes by default (nothing changed from the editor's defaults)
------------------------------------------------------------------------
Theory QS:GPW (Quickstep, Gaussian and plane waves). PBE. Basis level
DZVP-MOLOPT-SR-GTH, picked per element from BASIS_MOLOPT: O DZVP-MOLOPT-SR-GTH-q6,
Si DZVP-MOLOPT-SR-GTH-q4; potentials GTH-PBE-q6 / GTH-PBE-q4 from GTH_POTENTIALS
(library directory /usr/share/cp2k, CP2K's own). MGRID CUTOFF 400 Ry,
REL_CUTOFF 60 Ry, NGRIDS 4. SCF: OT on, minimizer DIIS, preconditioner
FULL_SINGLE_INVERSE, outer SCF on (MAX_SCF 30 inner x 10 outer, the
editor's defaults for a new calculation), EPS_SCF 1e-6, atomic guess. PERIODIC XYZ.
01 Energy run type: RUN_TYPE ENERGY_FORCE (the "Forces on atoms" box is ticked
by default in Runtype Details).
02 Geometry run type: RUN_TYPE GEO_OPT, &MOTION/&GEO_OPT OPTIMIZER BFGS,
MAX_ITER 100. The cell is fixed: CELL_OPT is not offered (issue #412).
Help pages the chapter should cite: cp2k-scf, cp2k-basis-potential (both in
chapters.py for this chapter).

GUI steps (from the help pages; NOT checked in a running ECCE in this job)
--------------------------------------------------------------------------
1. Builder: File > Import... (or Open) quartz.cif. ECCE builds the whole unit
   cell (9 atoms) from the symmetry operations (help: importing-a-structure).
2. Tools > Periodic Builder: Show Lattice is ticked by default; the
   Replicate button (PBCGUI "Replicate") makes the 2x2x2 supercell. A message
   about moving the atoms "to the SuperCell" may appear (Builder.C) -- the
   exact replicate fields and wording must be read off a running ECCE.
3. Organizer: new calculation with code CP2K; Calculation Editor: Theory
   QS / GPW, Theory Details (Functional PBE, Basis level, cutoffs, SCF box),
   Run Type Energy or Geometry, Runtype Details (Forces on atoms; Optimizer
   Method BFGS, maximum iterations). Save, then Launch.
4. Results: Organizer properties (total energy, SCF steps, forces, Mulliken
   and Hirshfeld charges); Builder Geometry Trace for the optimisation.

Coupling with other codes (route for the chapter)
-------------------------------------------------
Chosen: CP2K-relaxed cell -> ECCE's Diffraction panel (powder pattern), compared
with the pattern of the measured structure. This compares structures (peak
positions shift with Si-O and Si-O-Si changes; the cell itself is fixed, so
the shifts come from atom positions only -- intensities change, line positions
do not, which the chapter must say honestly; a cell optimisation would move
the lines but is not available, #412). No energies across methods.
- MACE pre-relaxation -> CP2K: not done; MACE is not installed on this
  machine and ECCE's Set up... (ecce-mlp-setup) would install it, which an
  agent may not do. If the lead wants it: MLP code, Geometry, on the 72-atom
  cell, then a new CP2K calculation from its final structure.
- Periodic -> cluster for a molecular code (e.g. an Si(OH)4-capped fragment
  for ORCA): ECCE cannot cut and cap a cluster; issue #1033 (open).

This requires
-------------
CP2K 2025.1 (Debian package cp2k 2025.1-1.1, cp2k.psmp, with cp2k-data for
BASIS_MOLOPT and GTH_POTENTIALS), Open MPI 5.0.7 (mpirun). Get CP2K from
cp2k.org or the distribution. ECCE's CP2K support is marked experimental.
